How it works

From Issuance to Verification
in Seconds

A fully decentralized pipeline using blockchain, IPFS, and public-key cryptography.

01
Institution Registers

Admin adds institution wallet address to the smart contract. Only registered institutions can issue certificates.

02
Document is Hashed

The certificate PDF is hashed using Keccak-256 in the browser. The hash — not the file — is stored on-chain, ensuring privacy.

03
Hash Stored On-Chain

Hash + IPFS CID are sent to the smart contract via MetaMask. The transaction is permanent, public, and tamper-proof.

04
Anyone Can Verify

Upload the same document — the hash is recomputed and compared against the blockchain. No login, no central server needed.
